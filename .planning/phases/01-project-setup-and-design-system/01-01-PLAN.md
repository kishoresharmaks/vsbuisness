## Phase 1 Plan: Project Setup & Design System Foundation

### Task 1: Next.js Project Initialization & Dependencies
- Scaffold Next.js 16+ App Router project in root directory `.` (or clean setup preserving `prompttobuild.md` and `.planning/`).
- Install dependencies: `framer-motion`, `lucide-react`, `clsx`, `tailwind-merge`.
- Configure `geist` font and Tailwind CSS.

### Task 2: Design Tokens & CSS Utilities Setup
- Define HSL/HEX design tokens in `app/globals.css`:
  - `--background`: `#FFFFFF`
  - `--secondary`: `#F7F8FA`
  - `--primary-text`: `#111111`
  - `--secondary-text`: `#5F6368`
  - `--muted-text`: `#8A8F98`
  - `--border-color`: `#E5E7EB`
  - `--accent-color`: `#2563EB`
  - Radii: `9999px` (buttons), `16px` (inputs), `24px` (cards), `28-32px` (large visuals)
- Implement `cn` utility in `lib/utils.ts`.

### Task 3: Base Primitives & Typography System
- Build `components/ui/container.tsx` (max-w 1280px / 1400px desktop with 32px/20px responsive padding).
- Build `components/ui/button.tsx` (pill shape 9999px radius, primary, secondary, outline variants).
- Build `components/ui/section-heading.tsx` (eyebrow, main title, subtitle).
- Build `components/ui/typography.tsx` (hero heading, section title, body text).
