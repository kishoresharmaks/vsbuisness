# Premium Web Development Services Platform

## Executive Summary
A world-class, modern web development services website designed for an ambitious digital product studio. Built with Next.js 16+, TypeScript, Tailwind CSS, React Bits, Framer Motion, and Geist Typography.

The design philosophy is **Minimal visual design + excellent typography + strong whitespace + subtle intelligent interactions**.

## Tech Stack
- **Framework**: Next.js 16+ (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Interactions/Visuals**: React Bits (primary UI interaction library) + Framer Motion
- **Icons**: Lucide React
- **Typography**: Geist (font-sans)
- **Component Primitives**: Custom design tokens + shadcn/ui (only when React Bits lacks standard primitive)

## Design System Tokens
- **Background**: `#FFFFFF`
- **Secondary Background**: `#F7F8FA`
- **Primary Text**: `#111111`
- **Secondary Text**: `#5F6368`
- **Muted Text**: `#8A8F98`
- **Border**: `#E5E7EB`
- **Primary Accent**: `#2563EB`
- **Radii**:
  - Buttons: `9999px`
  - Inputs: `16px`
  - Cards: `24px`
  - Large Visuals: `28–32px`
